# splitstream

Split filesystem stream paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/splitstream/

## Install / run

```bash
git clone https://github.com/theworker02/splitstream.git
cd splitstream
node src/cli.js
node --test
```
